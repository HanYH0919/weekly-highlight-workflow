# 按使用者范围审核

没有默认学科或期刊。以本地research_scope及当前用户指令为准，本文件是通用模板。本地profile的有效偏好须同步到research_scope，不能悄悄覆盖冻结范围。

topics按用户研究问题/领域；journal-informed按已读官方范围与近期内容；all按明确授权覆盖期刊全部领域。综合刊不自动等同于单一专业；排除项不继承作者个人偏好。

每篇完整摘要回答：具体问题？主要结果/方法增量？对应哪条用户问题或已声明范围？是否触及排除项？形成screening.question、contribution、relevance。仅共享词语、相同模型或热门方向不足以入选。

不强制某种学科、方法、材料或应用。默认处理有完整摘要的正式研究论文；预印本须显式选择来源。综述/评论/勘误如实标注类型，按本轮要求判断，不冒充新研究。

主题不符记主题排除，缺身份/日期/摘要记待核验；边界项给可核验理由，不设配额。Summary只写来源支持的结论和相关性，不编机制或应用。
