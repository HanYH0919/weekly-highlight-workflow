# Weekly Highlights 1.11

为使用者自选期刊和研究领域制作文献周报。没有默认期刊或学科，支持一刊或多刊；也可给agent期刊，让它读取官方范围与近期文章后说明并采用筛选范围。

首版前核验与去重，用户审核后下载合法可访问PDF并更新各刊Word。机械步骤使用可用便宜模型，视觉步骤使用安装时实际看图测试通过的模型。

把仓库链接交给具备联网、本地文件、命令和图片能力的agent，说：

> 帮我安装1.11版，先读START_HERE.md。让我选择期刊、研究领域、数据目录和模型；如果我只给期刊并授权自行判断，就先读取官网范围与近期内容。实际测试模型视觉能力后完成配置。

[首次配置](START_HERE.md) · [期刊与领域选择](references/selection-setup.md) · [平台适配](references/platform-adapters.md)

1.01升级后须显式选择期刊和领域，不能直接沿用作者旧范围。scope命令备份本地配置、保留原Word与模型；移出选择的旧档也不会删除。范围变化后旧审核/批准包失效。每台机器仍需自己的真实视觉记录。

通用RSS/Atom、文章元数据、显式选择器目录解析及浏览器辅助，不保证任意网站都全自动。默认上海时区近10天，可配置窗口。共享脚本/基础Word流程在Windows和Codex模型组合曾实测；其他客户端只有格式及流程适配，尚未逐一验收。

不含个人路径、论文历史、凭据或可复用视觉记录；不访问Zotero/EndNote，不绕过权限。网页聊天没有本地执行能力时不能只凭链接安装到电脑。

SHA256SUMS.txt覆盖可安装文件；.github属于仓库发布维护配置，不安装进技能目录。Release另附整包校验。运行测试：python -m unittest discover -s tests -v。MIT许可。

从1.01迁移时，旧的本地筛选profile会先备份，再换为中性模板，避免旧学科偏好残留；原偏好可从备份查阅，但仅将本人仍需要的内容明确加入新research_scope。
