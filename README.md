# Weekly Highlights 1.01

面向 ACP、ACP 相关 Egusphere 预印本和 PNAS 的个人文献周报技能。先核验来源、完成历史及跨版本去重，再输出便于复制的审核清单；用户确认后下载有权访问的 PDF 并更新滚动 Word。

支持标准 `SKILL.md`，提供 Codex、Pi、WorkBuddy、TRAE、OpenClaw 的安装适配说明。共享核心不依赖某个品牌模型、作者电脑路径或其他技能插件。

## 让 agent 从仓库安装

将本仓库链接交给本地 agent，并说：

> 请从这个 GitHub 仓库安装 weekly-highlight-workflow 1.01，先读 START_HERE.md。安装时让我选择本机数据根目录、已有历史或新库，以及可用的小模型；实际将随机图片题送入该小模型验证视觉能力，不能只看模型说明。如果小模型看不了图，请如实记录，并在我同意后使用通过实测的模型做视觉检查。完成配置后报告路径、模型、依赖和测试结果。

完整步骤在 [START_HERE.md](START_HERE.md)。普通网页对话如果没有本地文件、命令和图像工具，不能自动安装到电脑；请使用具备这些能力的本地 agent。

## 安装时会配置什么

- 数据工作根目录与 ACP/PNAS 历史 Word 路径；新用户可显式建立不含示例论文的空库。
- 筛选偏好副本，只保存在本机工作区。
- 便宜的机械执行模型，以及实际测试通过的视觉审阅模型。
- Python 依赖、LibreOffice 和 Poppler 路径。

配置在数据目录 `.weekly-highlights/`，不随源码发布。每台电脑/模型组合都需要自己的测试记录。换模型或供应商后重新测试；模型支持图片的声明不等于当前客户端可以把图片送进去。

## 工作流边界

含首尾10天，默认上海时区；只采用可核验日期和完整摘要。首版之前完成历史、本轮及可确认的跨版本去重。人工审核前不下载论文 PDF、不改 Word；旧档先验证备份，再安装新版。保留科学记号，并完整渲染检查实际新增与变化页面。

不访问或修改 Zotero/EndNote，不绕过访问控制，不包含机构权限或账号。PDF 无权访问时记录失败，不把错误网页当 PDF。

## 验证状态

共享脚本在 Windows 下测试，安装配置和视觉测试使用隔离合成资料；Codex 调度的一个小模型组合已完成两张随机图片的实际输入/记号/明显版式问题测试。该结果不随包复用，也不代表所有模型/平台或科学页面都能通过。

其他客户端具有格式及执行说明适配，尚未逐一在客户端端到端验收。具体调用能力以客户端、模型和用户授权为准。不宣称固定的省费比例或检索准确率。
